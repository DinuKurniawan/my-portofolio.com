1. Overview

ID: Thrift Corner adalah landing page + katalog untuk toko pakaian bekas kurasi (atasan, bawahan, jaket & outer, dress, tas, aksesoris). Tanpa backend/checkout kompleks — pembelian via chat WhatsApp dengan pesan otomatis. Responsif mobile-first, deploy statis di GitHub Pages.
EN: A static, responsive storefront/catalog for a curated thrift shop. No heavy backend — purchase via WhatsApp deep-link; hosted on GitHub Pages.

2. Masalah & Tujuan

UMKM thrift biasanya jualan hanya via DM/sosmed: katalog tercecer, pembeli bingung cara order, trust rendah. Tujuan: satu halaman yang menjelaskan brand, menampilkan koleksi terfilter, memandu 4 langkah belanja, dan mengonversi ke WhatsApp + Maps. [ISI: nama klien/toko jika ada].

3. Solusi

One-pager dengan IA jelas: Hero (2 CTA) → Kategori → Koleksi Terbaru + filter JS → Cara Belanja → Tentang Kami → Testimoni + form ulasan (upload foto, simpan lokal) → Kontak/Maps → Footer (pembayaran & ekspedisi).

4. Fitur Utama

  • Hero + CTA ganda (koleksi & WhatsApp)
  • 6 kategori + filter katalog instan tanpa reload
  • Tombol WA per produk dengan teks prefill (nama + kode item)
  • Cara Belanja 4 langkah
  • Testimoni, rating, form ulasan + upload foto (client-side)
  • Kontak WA/IG/TikTok + Google Maps Embed + info pembayaran/ekspedisi

5. Tech Stack

HTML5 Tailwind CSS Vanilla JS Material Symbols Google Maps Embed GitHub Pages

6. Tantangan & Pembelajaran

Tantangan: performa gambar & UX filter di HP, pesan WA yang konsisten, form tanpa backend. Pembelajaran: lazy-loading, accessible labeling, dan pola checkout ringan untuk UMKM. [ISI: kendala spesifik kamu].

7. Hasil

Website live, responsif, mudah dirawat pemilik toko (edit HTML/data saja). [ISI: traffic / jumlah produk / feedback pembeli — jangan dikarang]. Next: pencarian, keranjang ringan, CMS headless.
